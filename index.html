What's new in v0.3.0

A security-hardening release. Your notes and shares are safer by default.

  • Sanitized note import & quick notes — imported JSON and quick-note HTML are now stripped of scripts, event handlers, and dangerous URLs before they render.
  • Stronger HTML sanitizer — blocks javascript:, vbscript: and data: URLs, and removes svg, iframe, video, audio and other risky tags.
  • Share-link validation — share codes must point to a real Firebase database; anything else is rejected.
  • Owner-protected shared walls — only the wall owner can delete a shared wall; guests with the code can still edit notes.
  • Hardened runtime — cryptographically-random note IDs, explicit webSecurity, and null-byte-safe HTML escaping.

Install in seconds

Windows

  1. Run the .exe installer.
  2. Follow the setup and open Live PostIt from the Start menu.

Linux (AppImage)

  1. Make it executable: 
    chmod +x live-postit-0.3.0.AppImage
  2. Run it: 
    ./live-postit-0.3.0.AppImage
  3. If nothing opens, install libfuse2 and try again.
  4. Still blank? Launch with 
    ./live-postit-0.3.0.AppImage --no-sandbox --disable-gpu

Install to your apps menu (so it shows in your launcher):

bash live-postit-installer.sh

It downloads the AppImage, creates a desktop entry, wrapper script, and icon — no root needed.
