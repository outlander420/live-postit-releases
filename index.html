Sticky notes for your desktop.

Create walls, pin notes, format them with rich text — and share them live with friends. Free. Offline-first. Your data stays on your machine.

v0.1.0 · Windows & Linux · macOS soon

Multiple walls

Keep separate boards for work, shopping, ideas — switch with Ctrl+1…9.

Rich text notes

Bold, italic, underline, checklists and bullet lists. Drag, resize, recolor.

Share a wall live

Give friends a code to view & edit the same wall together in real time.

Sync across devices

Keep your walls in sync on all your machines via your own Firebase project.

Offline-first & private

Notes live locally. No account, no analytics, no tracking — only leave your device when you say so.

Automatic updates

Installed versions keep themselves up to date silently in the background.

Install in seconds

Windows

  1. Run the .exe installer.
  2. Follow the setup and open Live PostIt from the Start menu.

Linux (AppImage)

  1. Make it executable: 
    chmod +x live-postit-0.1.0.AppImage
  2. Run it: 
    ./live-postit-0.1.0.AppImage
  3. If nothing opens, install libfuse2 and try again.
