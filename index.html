Start in 60 seconds

Install it, click around, done. Here's the whole story in a few lines.

1

Install it

Grab your platform's file in the Download section and run it.

Linux AppImage? chmod +x live-postit-0.2.0.AppImage first.

2

Make a note

Double-click anywhere on the wall (or press Ctrl+N) and start typing. It saves itself.

3

Play around

Drag to move, resize from the corner, recolor, format with the toolbar, add a heading on the drag bar, and pin notes to other walls.

Keyboard shortcuts worth knowing

New noteCtrl+N
Switch wallCtrl+1…9
Bold / Italic / UnderlineCtrl+B Ctrl+I Ctrl+U
Duplicate noteCtrl+D
Undo / RedoCtrl+Z Ctrl+Y
Search everythingCtrl+F
Quick note (anywhere)Ctrl+Alt+Space
Delete noteDelete

Private by default: everything is saved on your machine — nothing is uploaded unless you turn on live sharing. Data lives in ~/.config/Live PostIt (Linux) or %APPDATA%\Live PostIt (Windows).

Install in seconds

Windows

  1. Run the .exe installer.
  2. Follow the setup and open Live PostIt from the Start menu.

Linux (AppImage)

  1. Make it executable: 
    chmod +x live-postit-0.2.0.AppImage
  2. Run it: 
    ./live-postit-0.2.0.AppImage
  3. If nothing opens, install libfuse2 and try again.
  4. Still blank? Launch with 
    ./live-postit-0.2.0.AppImage --no-sandbox --disable-gpu
