Live PostIt
What it does

A wall that works the way your brain does

Everything is local and private by default. Here's what you get out of the box.

Multiple walls

Keep separate boards for work, shopping, and ideas. Switch between them with Ctrl+1 through Ctrl+9, and quick notes get their own permanent wall.

Rich text notes

Bold, italic, underline, checklists, and bullet lists. Add a heading right on the drag bar, then drag, resize, and recolor.

Quick notes anywhere

Press Ctrl+Alt+Space from any app to capture a thought in a floating popup. It lands on your Quick Notes wall.

Share a wall live

Give friends a code to view and edit the same wall together in real time. Only you can delete it.

Sync across devices

Keep your walls in step on every machine through your own Firebase project. You own the data.

Offline-first and private

Notes live on your machine. No account, no analytics, no tracking. They only leave your device when you say so.

Attach files and images

Drag a photo or document onto a note. Images show inline; other files become chips you can save to disk.

Export a wall

Turn any wall into a single PNG or PDF for handoffs, docs, or sharing without the app.

Reorder your walls

Drag the wall tabs to put your boards in any order. The arrangement is saved automatically.

Automatic updates

Live PostIt checks for new versions and installs them from Settings, so you're always current.

Get started

Start in 60 seconds

Install it, click around, done. Here's the whole story in a few lines.

Install it

Grab your platform's file in the Download section and run it.

Linux AppImage? Run chmod +x live-postit-0.5.0.AppImage first.

Setup

Install in seconds

Windows

  1. Run the .exe installer.
  2. Follow the setup and open Live PostIt from the Start menu.

Linux (AppImage)

  1. Make it executable: 
    chmod +x live-postit-0.5.0.AppImage
  2. Run it: 
    ./live-postit-0.5.0.AppImage
  3. If nothing opens, install libfuse2 and try again.
  4. Still blank? Launch with 
    ./live-postit-0.5.0.AppImage --no-sandbox --disable-gpu

Install to your apps menu (so it shows in your launcher):

bash live-postit-installer.sh

It downloads the AppImage, creates a desktop entry, wrapper script, and icon. No root needed.
