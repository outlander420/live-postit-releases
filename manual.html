The Live PostIt Manual

Everything you need to get the most out of your sticky-note wall — from your first note to live sharing and cross-device sync.

Getting started

Install

Download the build for your platform from the Download page:

  • Windows — run the .exe installer and follow the prompts.
  • Linux — run the AppImage, or use the one-click installer to add a desktop entry.
  • macOS — coming soon.
Linux AppImage: run chmod +x live-postit-0.3.0.AppImage first. If the window is blank, launch with --no-sandbox --disable-gpu (the installer does this for you).

Make your first note

Double-click anywhere on the wall — or press Ctrl+N — and a new note appears. Start typing; it saves automatically. You're already using Live PostIt.

Notes

Notes are the individual sticky notes on your wall. Here's everything they can do.

Create & edit

  • Create: double-click the wall, press Ctrl+N, or use the + button.
  • Edit: click into a note and type. Changes save as you go.
  • Heading: click the drag bar (the strip at the top of a note) to add a bold heading. Press Enter to save, Escape to cancel.

Rich text

Select text inside a note and use the toolbar (or shortcuts) to format it:

  • Bold Ctrl+B, Italic Ctrl+I, Underline Ctrl+U
  • Strikethrough, Checklist, and Bullet list from the toolbar

Move, resize, recolor

  • Move: drag the note by its grip bar.
  • Resize: drag the corner handle.
  • Recolor: pick a color from the palette dots — blue, grey, white, pink, or black.

Duplicate, move to a wall, delete

  • Duplicate: Ctrl+D or the duplicate button makes a copy.
  • Copy / move to a wall: use the wall button on a note. Hold Shift to move instead of copy.
  • Delete: press Delete or the × button. Deleted notes go to the Trash.
Undo / redo: press Ctrl+Z to undo and Ctrl+Y to redo most actions.

Walls

A wall is a board that holds many notes — think of it as one project or topic. Use walls to keep things organized.

  • Create: click the + tab to add a new wall.
  • Switch: click a tab, or press Ctrl+1 through Ctrl+9.
  • Rename: double-click a wall's tab and type a new name.
  • Delete: click the × on a wall tab.

Quick Notes wall

There's a permanent Quick Notes wall that you can't delete. Every note you capture with the global shortcut lands here, so quick thoughts always have a home.

Trash

Deleted notes aren't gone for good — they move to the Trash wall. Open it to restore a note or empty it to delete for good.

Quick notes

Need to capture something without leaving your current app? Press Ctrl+Alt+Space from anywhere on your desktop.

  • A small popup appears at your cursor. Start typing.
  • Pick a color if you like.
  • Save: Ctrl+Enter or the Save button.
  • Discard: Escape or the Discard button.

The note is added to your Quick Notes wall.

Search

Press Ctrl+F to search across all your walls at once.

  • Type to see live matches with a running count.
  • Press Enter / Shift+Enter to jump between matches.
  • Press Escape to close the search.

Sharing a wall

Share a wall so friends can view and edit it live, in real time. Sharing runs over your own Firebase project, so you control where the data lives.

Set up (one time)

  1. Create a free project at console.firebase.google.com.
  2. Add a Realtime Database and enable Anonymous authentication.
  3. Copy your database config and paste it into Live PostIt's Settings.

Share

  1. Open the wall's menu and choose Share.
  2. Live PostIt generates a short share code.
  3. Send the code to a friend. They enter it to join the wall.
  4. Everyone with the code can edit notes in real time. Only you (the owner) can delete the wall.
Privacy note: anyone with the share code can edit the wall. Treat the code like a password.

Sync across devices

Keep your walls in step on every machine. Sync uses the same Firebase project as sharing.

  1. Set up your Firebase project (see Sharing).
  2. Paste your database config into Settings and enable sync.
  3. Your walls now sync across any device signed into the same Firebase project.

Sync is optional and offline-first — if you're offline, your notes stay local and sync when you reconnect.

Export & import

Back up your walls or move them to another computer.

  • Export: saves all your walls to a JSON file. Use this for backups or handoffs.
  • Import: loads walls from a JSON file. You can choose to merge or replace your current walls.
Tip: export regularly if you rely on a single machine. The app also keeps 30 rolling automatic backups in your data folder.

Settings

Open the settings menu (gear icon) to control how Live PostIt behaves:

  • Launch at startup — start Live PostIt when you log in.
  • Start minimized to tray — begin in the system tray instead of a window.
  • Dark / light mode — toggle the theme (also via the sun/moon button).
  • Sync & sharing — paste your Firebase config and enable sync/sharing.

You can also reach Quick note, Show/Hide, Open at login, and Quit from the system tray icon.

Where your data lives

Live PostIt is offline-first. Your notes are stored on your own machine:

  • Linux: ~/.config/Live PostIt
  • Windows: %APPDATA%\Live PostIt

Your walls are saved in a walls.json file, and the app keeps 30 rolling backups alongside it. Nothing is uploaded unless you turn on sharing or sync.

Troubleshooting

The window is blank (Linux)

Some systems need extra flags. Launch with:

./live-postit-0.3.0.AppImage --no-sandbox --disable-gpu

The one-click installer bakes these in automatically.

AppImage won't run (Linux)

Make sure it's executable and that libfuse2 is installed:

chmod +x live-postit-0.3.0.AppImage
sudo apt install libfuse2

Sharing isn't updating

Check that your Firebase project has Anonymous auth enabled and that the database rules allow reads/writes for authenticated users. Publishing rules can take up to 24 hours to fully take effect.

I lost my notes

Check the Trash wall first. If you've exported before, re-import your latest JSON backup. Otherwise, look in your data folder for the 30 rolling backups.
