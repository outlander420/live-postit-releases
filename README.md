# Live PostIt — Release Binaries

This repository hosts **only the release binaries and auto-update metadata** for
[Live PostIt](https://github.com/outlander420/live-postit) (the source lives in the private
`live-postit` repository).

Everything here is a build artifact — there is no source code.

Download the installer for your platform from the **Releases** tab (right side / top of this page).

Auto-updates read `latest.yml` (Windows) and `latest-linux.yml` (Linux) from here.
